## General

| Atajo | Accion |
|---|---|
| `Super + Return` | Terminal (alacritty) |
| `Super + Space` | Menu (wofi) |
| `Super + E` | File manager (dolphin) |
| `Super + Q` / `Super + C` | Cerrar ventana |
| `Super + V` | Toggle flotante |
| `Super + S` | Captura de pantalla (selección con slurp) |
| `Super + Escape` | Menú de energía (wofi) |
| `Super + Shift + Q` | Salir de Hyprland |
| `Super + Shift + L` | Bloquear pantalla (hyprlock) |
| `Super + Shift + R` | Recargar config |

## Mouse

| Atajo | Accion |
|---|---|
| `Super + Left drag` | Mover ventana |
| `Super + Right drag` | Redimensionar ventana |

## Workspaces

| Atajo | Accion |
|---|---|
| `Super + 1..5` | Ir a workspace 1-5 |
| `Super + Shift + 1..5` | Mover ventana a workspace 1-5 |

## Layouts

| Atajo | Accion |
|---|---|
| `Super + Shift + D` | Layout Dwindle |
| `Super + Shift + M` | Layout Master |
| `Super + Shift + S` | Layout Scrolling |
| `Super + Shift + C` | Layout Monocle |

### Master layout

| Atajo | Accion |
|---|---|
| `Super + H` | Quitar ventana del master |
| `Super + L` | Agregar ventana al master |

### Window navigation (todos los layouts)

| Atajo | Accion |
|---|---|
| `Super + Left/Right` | Mover foco lateral |
| `Super + Up` | Mover foco arriba (ciclo en Monocle) |
| `Super + Down` | Mover foco abajo (ciclo en Monocle) |

### Scrolling layout

| Atajo | Accion |
|---|---|
| `Super + Ctrl + Left` | Reducir columna |
| `Super + Ctrl + Right` | Agrandar columna |
| `Super + Ctrl + P` | Promover ventana a columna propia |
| `Super + Ctrl + O` | Consolidar/expulsar ventana |

## Volume

| Atajo | Accion |
|---|---|
| `XF86AudioMute` | Silenciar/activar audio |
| `XF86AudioLowerVolume` | Bajar volumen |
| `XF86AudioRaiseVolume` | Subir volumen |
| `XF86AudioMicMute` | Silenciar/activar micrófono |

## Brightness

| Atajo | Accion |
|---|---|
| `XF86MonBrightnessDown` | Bajar brillo |
| `XF86MonBrightnessUp` | Subir brillo |
